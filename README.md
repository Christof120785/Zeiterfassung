# Zeiterfassung

Persönliche Arbeitszeiterfassung als installierbare Web-App (Android und PC), ohne Server.

- Start/Ende stempeln, Uhrzeiten oder Stunden direkt eintragen, Pause pro Tag
- Urlaub, Krank, Feiertage Niedersachsen automatisch, Heiligabend/Silvester halber Tag
- Wochen-/Monatsübersicht, Überstundenkonto, Resturlaub
- Abgleich zwischen Geräten über OneDrive (`Apps/Zeiterfassung/zeiterfassung.json`)

Die Daten liegen nur im Browser des Geräts und im eigenen OneDrive, nicht in diesem Repository.
